# 무료 티어 조사 (2026-11-26, 웹검색 요약 — 공식 페이지 원문을 직접 열람하지는 못함)
## Render (Node/WebSocket 게임 서버)
- 무료 웹 서비스는 **15분간 인바운드 트래픽이 없으면 스핀다운**(WebSocket 메시지도 트래픽으로 인정). 재기동에 약 1분.
- Render가 언제든 재시작 가능 → **열린 WebSocket이 끊길 수 있음**. 파일시스템은 **임시(재시작 시 소실)**.
- 커뮤니티에는 "약 5분 후 끊김" 보고가 있으나 공식 근거는 못 찾음(CONFLICTING).
- 유료(Starter 약 $7/월, 미검증)는 스핀다운 없음. **결제하지 않음**.
## Neon (Postgres)
- 최신 공식 FAQ(2026-11-03 갱신): 프로젝트 100개, 프로젝트당 100 CU-hours, 1 GB 저장, 5분 후 scale-to-zero, 카드 불필요. 한도 초과 시 쓰기 실패/정지(과금 없음).
- 구 자료(0.5GB, 20 프로젝트 등)와 상충 → 최신 FAQ 수치 사용, 배포 전 재확인 필요.
## Cloudflare Durable Objects (대안)
- 무료는 SQLite 기반 DO만 가능, 총 5GB, 일 10만 요청(00:00 UTC 리셋). WebSocket 수신 메시지는 20:1로 과금 환산. **기존 Node 서버를 그대로 못 올림 → 재작성 필요.**
## 결정
- 프런트: GitHub Pages(정적). 서버: Render 무료 Node + **Neon 무료 Postgres**(Render 디스크 소실 문제 해결). 
- 근거: 현 코드(ws/Node)를 재작성 없이 배포 가능, 데이터는 Postgres에 영속.
- 알려진 제약: 콜드스타트 ~1분(클라이언트는 "서버 시작 중" 표시 후 재시도), 재시작 시 접속 끊김(재접속 로직 있음), 한도 도달 시 저장 실패 → 입장 제한 필요.
- 무료 티어를 유지하려는 **인위적 핑 트래픽은 사용하지 않음**(약관/정책 존중).
